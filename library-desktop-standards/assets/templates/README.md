# Mẫu code

Lấy mẫu phù hợp, đổi tên theo use case và điều chỉnh. Mẫu dùng module mượn sách (`CIR`) làm ví dụ.

| File | Dùng khi |
|---|---|
| `Command.Handler.Validator.cs` | Tạo use case ghi (Command + Handler + Validator) |
| `Entity.Configuration.cs` | Tạo entity và cấu hình EF Core |
| `ViewModel.cs` | Tạo ViewModel WPF |
| `Handler.Tests.cs` | Viết unit test cho handler |
